# KT2 Kubernetes

Я решил воспользоваться проектом чата и задеплоил его в кубернетис

## Развернуто
 отдельно развернуты фронт, бэк и бд, секреты для закрытых данных (пользователь и пароль от постгрес, jwt ключ и тд), configmap для того что может видеть любой (URL, время жизни токена и тд)

## Ход действий 
- я сначала развернул кластер с помощью kind открыв ему нужные порты и установил метку для того чтобы поставить ingress nginx (для маршрутизации в кластере между контейнерами)
- после этого собрал образы фронта и бэка и загрузил их в кластер
- написал манифесты они в папке [k8s](./k8s)
- пронумеровал каждый манифест в названии файла чтобы применить все манифесты из папки в правильном порядке одной командой
- потом тоже самое сделал через helm создал шаблон [чарта](./chart), переменные вынес в отдельный файл и применил их в манифестах
- секреты не лежат внутри чарта для безопасности
